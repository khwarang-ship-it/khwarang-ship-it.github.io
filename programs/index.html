명석고 전용 프로그램 안내

명석고 선생님들을 위해 만든 프로그램들의 사용 안내를 모아둔 페이지입니다. 항목을 눌러 펼쳐보세요.

건의·버그 제보
M-Desk 바탕화면을 대시보드처럼 — 카드형 위젯 프로그램

선생님들의 바탕화면을 대시보드처럼 사용할 수 있게, 원하시는대로 카드를 배치해 고정시킬 수 있는 프로그램입니다.

카드

  • 업무 도구 — 결석계를 작성해서 PDF 파일로 만들거나, 상벌점 입력 및 조회를 온라인 교무실과 연동해 바로 하실 수 있습니다. 담임 선생님은 자율학습 시스템 담임모드를 바로 쓰실 수 있고, 자습참여 현황 카드도 배치할 수 있습니다.
  • 포스트잇 · 할 일 — 설명 입력 칸에 파일 링크(편집 창으로 드래그)와 이미지(Ctrl+V)를 넣으실 수 있습니다.
  • 명렬표 — 체크박스와 메모 열을 추가해서 쓰실 수 있습니다.
  • 액자 — 사진을 바탕화면에 카드 형식으로 고정하실 수 있습니다.

공통 옵션

  • 부팅 시 자동 실행 — 작업표시줄 오른쪽 아래 트레이 아이콘에서 켜고 끄실 수 있어, 컴퓨터가 켜질 때 카드들을 바로 띄우실 수 있습니다.
  • 카드 선택과 고정 — 공통 설정에서 맘에 드는 카드들만 활성화하시고, 각 카드를 오른쪽 버튼으로 눌러 바탕화면 고정, 카드 설정을 하실 수 있습니다.
  • 디자인 커스텀 — 원하시는 형태의 디자인으로 카드를 커스텀할 수 있게 준비해두었습니다.
선생님들께서 주신 건의사항을 반영해 계속 기능을 추가하고 있습니다. 이미 설치해서 쓰고 계시면 프로그램을 다시 실행할 때 자동으로 업데이트됩니다. 아직 설치 전이시면 안내 메일의 첨부파일로 설치해 주세요. 테스트 기간이 짧아 자잘한 버그가 있을 수 있는데, 제보해 주시면 감사하겠습니다.

백신(V3) 실행 알림이 뜨는 경우 대부분의 프로그램에 공통되는 안내

AhnLab V3가 설치된 컴퓨터에서는 위 프로그램들을 처음 실행할 때 클라우드 평판 기반으로 파일 실행을 탐지했다는 알림이 뜰 수 있습니다. 아직 널리 배포되지 않은 프로그램이라 나타나는 정상적인 안내이며, 아래처럼 처리하시면 됩니다.

  1. 알림 창에서 파일 처리 방법을 「실행 후 다음부터 묻지 않음」으로 선택하고 확인을 누릅니다.
  2. 이후로도 계속 뜬다면, 작업표시줄 트레이의 V3 아이콘을 마우스 오른쪽 버튼으로 클릭 → 환경 설정을 엽니다.
  3. 왼쪽 메뉴에서 Active Defense → Active Defense 설정을 선택합니다.
  4. 우측 화면에서 ASD 네트워크 참여와 Active Defense 사용을 모두 체크한 뒤 적용 → 확인을 누릅니다.
이 설정을 켜 두면 해당 프로그램이 설치된 폴더가 신뢰 목록으로 등록되어, 다음부터는 실행 알림이 뜨지 않습니다.
